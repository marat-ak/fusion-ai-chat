# fusion-ai-chat

`xxx-gnimsys-ai-chat`: a Preact/JET chat component (JET pack `xxx-gnimsys-ai`, VComponent `chat`) that a
Fusion customer embeds in a Visual Builder App UI extension to talk to their Oracle AI Agent Studio
agents, configured by a versioned JSON config.

Design: `../docs/superpowers/specs/2026-10-21-fusion-ai-chat-design.md`. Developer persona:
`../knowledgebase/fusion-ai-chat-dev.md`.
